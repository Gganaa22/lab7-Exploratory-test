\# BUG-05: Хайлт том/жижиг үсгийг ялгаж, жижиг үсгээр бичихэд ном олдохгүй



Орчин: Уншлагын жагсаалт v2.0, Google Chrome 155.0.8059.85, Windows 11, 2026-10-20

Урьдчилсан нөхцөл: node app.js-ийг шинээр асаасан (анхны 3 ном)



\## Дахин гаргах алхам

1\. Браузераар http://localhost:3000 нээнэ.

2\. "Хайх үг" талбарт `Clean` гэж бичээд "Хайх" товчийг дарна. Clean Code ном харагдана.

3\. Талбарыг `clean` гэж (жижиг үсгээр) өөрчлөөд "Хайх" товчийг дахин дарна.



Хүлээгдэж байсан: Спецификац: «Хайлт гарчиг болон зохиолчоос хайх ба том/жижиг үсэг ЯЛГАХГҮЙ». `clean` гэж хайхад `Clean` гэсэн адил үр дүн гарах ёстой.

Бодит үр дүн: `Clean` гэж хайхад Clean Code олдох ч `clean` гэж хайхад хүснэгт хоосон болно. Зохиолчоор хайхад мөн адил (`martin` олдохгүй, `Martin` олдоно).

Ноцтой байдал: Major — хэрэглэгч үсгийн хэлбэрээс шалтгаалан номоо олж чадахгүй, хайлтын гол үүрэг алдагдана.
