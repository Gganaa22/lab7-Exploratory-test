\# BUG-08: Буруу JSON биетэй POST /api/books хүсэлтэд 400 биш, 200 OK буцаана



Орчин: Уншлагын жагсаалт v2.0, curl.exe (Windows PowerShell), Windows 11, 2026-10-20

Урьдчилсан нөхцөл: node app.js-ийг шинээр асаасан (анхны 3 ном)



\## Дахин гаргах алхам

1\. Тусдаа PowerShell цонхонд дараах командыг ажиллуулна:

&#x20;  `curl.exe -s -i -X POST localhost:3000/api/books -d "буруу оролт"`

2\. Гарсан HTTP статусын мөрийг харна.



Хүлээгдэж байсан: Спецификац: «API: буруу JSON биетэй POST хүсэлтэд 400 алдаа буцаана». Статус нь `HTTP/1.1 400 Bad Request` байх ёстой.

Бодит үр дүн: `HTTP/1.1 200 OK` статус, `{"result":"OK"}` бие буцна. Сервер буруу оролтыг алдаа гэж мэдээлэхгүй, амжилттай боловсруулсан мэт хариулна.

Ноцтой байдал: Major — API-г дуудагч систем өөрийн хүсэлт буруу байсныг мэдэхгүй, алдаа далд үлдэнэ.
