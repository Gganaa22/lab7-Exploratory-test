\# BUG-07: "Хуучин хувилбар" линк дээр дарахад "Internal Server Error" (HTTP 500) гарна



Орчин: Уншлагын жагсаалт v2.0, Chrome, Windows 11, 2026-10-20

Урьдчилсан нөхцөл: node app.js-ийг шинээр асаасан (анхны 3 ном)



\## Дахин гаргах алхам

1\. Браузераар http://localhost:3000 нээнэ.

2\. Хуудасны доод талын "Хуучин хувилбар" линк дээр дарна (хаяг нь http://localhost:3000/old болно).



Хүлээгдэж байсан: Спецификац: «бүх хуудас, линк ажиллана». Линк нь хуучин хувилбарын хуудсыг нээх эсвэл ойлгомжтой хариу өгөх ёстой.

Бодит үр дүн: Цагаан дэлгэц дээр зөвхөн `Internal Server Error` гэсэн текст гарна. Хуудас ажиллахгүй.

Ноцтой байдал: Major — хуудсан дээрх линк эвдэрсэн, хэрэглэгч хаашаа ч явж чадахгүй.
